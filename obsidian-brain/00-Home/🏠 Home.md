## 🚀 Quick Commands

```bash
# Start dev server
yarn dev

# Run a single test
yarn test packages/core/server/src/__tests__/Application.test.ts

# Lint touched files
yarn eslint --fix packages/path/to/file.ts

# Upgrade & sync DB
yarn nocobase upgrade
```
