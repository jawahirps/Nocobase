# TopGear Auto Website

Marketing website for [topgearauto.com](https://topgearauto.com) — a single-page React app with scroll-triggered animations powered by Framer Motion.

## Stack

- React 18 + TypeScript
- Vite 5
- Framer Motion 11 (entrance animations, scroll-triggered reveals, animated counters, hover springs)

## Sections

1. **Hero** — staggered headline reveal with a floating rating badge
2. **Stats** — animated number counters triggered on scroll
3. **Featured Inventory** — vehicle cards with hover lift
4. **Services** — six service offerings with staggered reveal
5. **Testimonials** — customer reviews
6. **Call to Action** — contact panel
7. **Footer**

## Develop

```bash
cd topgearauto-website
npm install
npm run dev      # local dev server
npm run build    # production build to dist/
```

This folder is a standalone project and is not part of the NocoBase yarn workspace.
